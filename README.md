# andgaa.github.io

Personal site for Andreas Gaardsted Vad, served by GitHub Pages at https://andgaa.github.io (Danish) and https://andgaa.github.io/en/ (English).

Plain HTML and CSS with a small script for the strengths highlight and the screenshot lightbox – no build step needed to publish. Edit the HTML files and push to `main`.

The pages under `da/` only redirect old links to the Danish pages, which now live at the root.
