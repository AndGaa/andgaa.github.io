Ferie- og fraværsapp

Ét sted, hvor medarbejdere registrerer fravær, og ledere godkender det og holder styr på feriesaldiene.

År
2024 – 2026
Stack
Python, Django, PostgreSQL
Hosting
Azure App Service, Blob Storage, GitHub Actions
Integrationer
Microsoft-login, Slack, mail
Brugere
Medarbejdere, ledere og HR – på computer, tablet og telefon

Problemet

Ferie, sygedage og hjemmearbejde blev registreret forskellige steder, og det krævede manuelt arbejde at holde styr på hver medarbejders feriesaldo på tværs af ferieår. Lederne havde ikke ét samlet overblik over, hvem der var væk, og hvad der ventede på deres godkendelse.

For medarbejdere

  • Registrér ferie, sygdom, barns sygedag, fridage, orlov og hjemmearbejde
  • Se den resterende feriesaldo for det aktuelle ferieår med det samme
  • Følg status på hver registrering og se årets historik pr. måned
  • Log ind med Microsoft-arbejdskontoen og få en mail, når en anmodning er godkendt eller afvist

For ledere

  • Overblik over dagens godkendte registreringer og dem, der venter på godkendelse
  • Alle registreringer pr. medarbejder og type i én graf og tabel
  • Godkend eller afvis med ét klik – ledere og HR får besked på mail, når der kommer noget nyt
  • Rapporter om fremmøde, registreringer og ferie
  • Beskeder til teamet på Slack direkte fra appen

Ferieår

Det danske ferieår løber fra september til august, og saldiene skal føres korrekt videre. Det klarer siden til ferieadministration: nyt ferie- eller kalenderår, overførsel af dage mellem år og registrering af fælles feriedage for alle på én gang.

Danske helligdage hentes automatisk ind i kalenderen, og den 6. ferieuge holdes adskilt fra de fem lovpligtige.

Sådan er den bygget

En Django-app på PostgreSQL med rollebaseret adgang, så medarbejdere, projektledere og HR hver især ser det, de skal. Profilbilleder og andre uploads ligger i Azure Blob Storage.

Den kører på Azure App Service med separate test- og produktionsmiljøer, og GitHub Actions deployer automatisk til hvert af dem.
