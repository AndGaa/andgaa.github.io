App til godkendelse og fakturering

En webapp, hvor projektledere godkender hvert projekts timer måned for måned og sender dem videre til timesedler og fakturaer.

Stack
Python, Azure Functions, Jinja, JavaScript
Lagring
Azure Table Storage, Blob Storage
Integrationer
ClickUp, Power Automate, e‑conomic
Kompetencer
Fullstack-udvikling, procesdesign, datamodellering

Problemet

Hver måned skal de timer, der er registreret i ClickUp, tjekkes, godkendes og faktureres – projekt for projekt. Projekterne følger forskellige regler: timepriser, budgetter, klippekort og kunder, der vil have en timeseddel med fakturaen. At gøre det i hånden på tværs af mange projekter tog tid og gav plads til fejl.

Sådan virker den

  • For hvert projekt og hver måned bygger appen en godkendelse ud fra de tidsregistreringer, synkroniseringen gemmer, kombineret med projektdata fra ClickUp
  • Projektlederen godkender timerne, justerer hvor mange der skal faktureres og tilføjer en kommentar
  • Hver godkendelse går gennem tydelige statusser: afventer, klar, godkendt, sendt til fakturakladde og faktureret
  • Flere måneder kan samles i én faktura eller én timeseddel
  • Klippekort synkroniseres fra ClickUp og faktureres for sig

Koblet til resten

  • Godkendelse, fakturering og afsendelse af timesedler starter Power Automate-flows, der laver timesedler og fakturakladder
  • Fejler et flow, forbliver godkendelsen uændret, og brugeren får en klar fejlbesked – så intet faktureres to gange eller går tabt
  • Projektoplysninger som kunde, produkt og fakturatekst følger med hvert projekt, så fakturaerne bliver rigtige

Arkitektur

Én Azure Function-app leverer både API og brugerflade: en Jinja-skabelon med ren JavaScript i frontenden og HTTP-endpoints bagved.

Koden er delt i repositories oven på Azure Table Storage, services for hvert workflow og en lille JSON-cache i Blob Storage, der holder appen hurtig og kan opdateres efter behov.
