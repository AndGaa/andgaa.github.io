Time tracking report

A Power BI report that shows where project hours go, built on data pulled straight from ClickUp and e‑conomic.

Role
Data analyst
Stack
Power BI, Power Query (M), DAX, Power Automate
Data sources
ClickUp API, e‑conomic API
Skills
Data modeling, API integration, visualization

The problem

The business had no clear view of how time was spent across projects and tasks. Hours were logged in ClickUp and invoicing lived in e‑conomic, so answering simple questions – which projects are over budget, how much of our time is billable – meant manual exports and spreadsheets.

The report brings both sources together and gives project managers and leadership one place to follow time, budgets and resource use.

Key features

  • Billable versus unbillable time, filtered by date, project manager, client and status
  • Budget status per project: over, near or within budget
  • Drill-through from the overview to a single project and the people working on it
  • Role-based access, so each person sees the data they should
  • On-demand refresh from the report through a Power Automate flow

The model

ClickUp was the team's project tool, and its structure of spaces, folders and lists didn't match the project structure needed for reporting. Project metadata was kept in ClickUp in its own pseudo-structure, so the two could evolve separately.

I built the extraction in Power Query (M) against the ClickUp API, pulling project and time entry data and linking them through a bridge table. Invoices, prepaid hours and budgets from e‑conomic sit alongside, all sharing one calendar. That makes it possible to aggregate hours accurately by project, client and employee.

Challenges and solutions

The ClickUp API limits how much data a single request can return. I added pagination to the extraction so large datasets come through in manageable chunks.

The API can also return time entries in a denormalised form. By staging that data first and reshaping it in Power BI, I no longer had to fetch tasks a hundred at a time, which made the refresh considerably faster and more reliable.
