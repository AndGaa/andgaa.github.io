What I'm good at

Three problems I solve – each with a project that shows how.

Power BI that people trust

Plenty of companies have lots of data but no report that answers what management is actually asking. I start with the question, then build the Power BI model and report that give the answer in seconds – and are easy to extend when the questions change.

Power BI, DAX, Power Query, PBIP

Data pipelines that run on their own

Manual exports and copy-paste between systems eat hours and invite mistakes. I build pipelines that pull data from the systems you already use, gather it in one place and keep it up to date – without anyone having to press a button.

Python, Azure Functions, Parquet, Data Lake

Business apps around the data

Some processes live in spreadsheets, emails and one colleague's head. I turn them into simple apps with sign-in, approvals and automation, so the work is done the same way every time – and the data ends up where reporting can use it.
